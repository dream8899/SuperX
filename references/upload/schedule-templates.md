# 定时发表计划模板

适用于用户明确授权定时发表的视频号账号。位置字段默认不显示地址（上传页「短标题」后），
只有用户明确要求时才填写。

## 模板一：每日 N 条 · 固定四节点

- 适用：指定单个视频号账号；用户指定每天发表视频数量 N。
- 固定发布节点：上午 9:00、中午 12:00、下午 3:00、晚上 8:00。
- 排期规则：按序取前 N 个节点，N 最大为 4：
  - N=1 → 09:00
  - N=2 → 09:00、12:00
  - N=3 → 09:00、12:00、15:00
  - N=4 → 09:00、12:00、15:00、20:00
- N > 4：停止并提示用户调整数量或改用手动排期/其他模板；模板一每日最多 4 条。
- 执行：先按既有流程存草稿并核验；取得用户明确授权后，用
  `sau tencent upload-video --schedule "YYYY-MM-DD HH:MM"` 逐条设置定时，并在平台核验
  排期结果。
- 边界：
  - 定时发表属于公开发布，必须用户明确授权；
  - 同一账号一次只运行一个批次/窗口，不并发；
  - 位置默认不显示地址；
  - 完成或中断后按账本契约回写发布状态。

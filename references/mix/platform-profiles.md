# 来源平台分析预设

平台信息只调整分析窗口、阈值与风险提示，不固定减秒，也不自动添加或移除平台标识。

| Profile | 常见需复核内容 | 处理原则 |
|---|---|---|
| `douyin` | 末尾推荐页、作者卡、停留帧、黑屏或空镜 | 加强尾部扫描，以多证据判断，不固定裁切时长 |
| `tiktok` | 循环式结尾、结束卡、静帧与音乐继续 | 避免把循环叙事或带声音静帧误删 |
| `instagram` | Reel 循环、品牌 end card、字幕安全区 | 区分创作者自有品牌包装与无效片尾 |
| `youtube-short` | CTA、订阅提示、结束卡、口播尾句 | CTA 可能是有效内容，默认报告而非删除 |
| `generic` | 无平台先验 | 使用最保守阈值 |

这些模式会随平台和创作者模板变化。实际判断以当前视频证据为准，不把平台名称作为删除依据。
